Juste après l’écran d’accueil, un court assistant configure Diana pour votre station. Cela prend environ une minute. Chaque réponse est enregistrée dès que vous la donnez ; s’arrêter en cours de route ne fait rien perdre.

![Étape 2 de l’assistant : votre station, avec indicatif, indicatif portable et locator](../../../../../assets/screens/phone-wizard-station.webp)

## Les étapes

1. **Langue.** L’assistant démarre en anglais. Touchez votre langue : EN, NL, FR, DE, DA, IT, ES ou PT. Tout change immédiatement.
2. **Votre station.**
   - **Indicatif** : votre indicatif habituel, par exemple `F4ABC`. Diana l’utilise comme spotter, et il détermine le pays que Diana choisit pour vous.
   - **Indicatif portable** : celui que vous utilisez sur le terrain, par exemple `F4ABC/P`. Diana le remplit comme activateur quand vous vous annoncez ou annoncez une activation.
   - **Locator Maidenhead** : six caractères, par exemple `JN18EU`. Touchez **Depuis le GPS** pour le remplir à partir de votre position. Tant qu’il n’y a pas de position GPS, Diana part de votre locator : pour la carte au démarrage, les distances dans Infos terrain et les lignes vers les spots.
3. **Votre pays.** Le pays que Diana charge avec ses vraies limites. Diana en propose un d’après votre indicatif. Voir [Votre pays](/fr/guide/settings/your-country/).
4. **Mots rapides.** Cinq mots que vous pouvez ajouter à la remarque d’un spot d’un seul toucher. Touchez **Remplir avec des exemples** pour commencer, ou laissez-les vides : un champ vide ne donne simplement pas de bouton.
5. **Liste des bandes.** **Toutes les bandes** (160 m à 23 cm) ou **HF uniquement** (80, 40, 30, 20, 15 et 10 m) pour la liste quand vous annoncez une activation.
6. **Statistiques.** Seulement si vous n’avez pas encore dit oui : une seconde question, polie, pour savoir si vous voulez aider avec des statistiques anonymes.
7. **Terminé.** Vos réglages sont enregistrés. Ils restent dans le navigateur de cet appareil tant que vous n’effacez pas les données du navigateur.

Utilisez **Suivant** et **Précédent** pour passer d’une étape à l’autre. **Passer l’introduction** arrête l’assistant ; vous pouvez toujours compléter le reste dans les Réglages.

:::note
Tout ce que vous saisissez ici peut être modifié plus tard dans les **Réglages**. Vous pouvez aussi y relancer l’assistant : **Réglages** › **Relancer l’assistant de démarrage**.
:::

## Ensuite : la visite

À la fin, Diana propose une courte visite. Voir [La visite guidée](/fr/guide/start/tour/).
