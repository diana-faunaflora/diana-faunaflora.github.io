Sur Android, Diana s’installe comme une application ordinaire : une icône sur l’écran d’accueil, sa propre fenêtre, et elle continue de fonctionner sans réseau.

## Le plus rapide : depuis Diana

1. Ouvrez **diana-onff.github.io** dans **Chrome** (Edge et Samsung Internet fonctionnent aussi).
2. Touchez **Réglages** en bas à droite (la roue dentée).
3. Faites défiler jusqu’à **Installer comme application** et touchez **Installer sur cet appareil**.
4. Le téléphone demande une confirmation. Touchez **Installer**.
5. Diana a maintenant sa propre icône sur l’écran d’accueil. Ouvrez-la désormais depuis là.

:::tip
La première fois que vous ouvrez la carte, Diana peut aussi afficher une barre en bas : *« Ajouter Diana comme application sur cet appareil ? »*. Touchez **Installer** et c’est fait. Si vous touchez **Pas maintenant**, la barre ne revient pas ; le bouton dans les Réglages reste toujours disponible.
:::

## Par le menu du navigateur

Si vous ne voyez pas le bouton d’installation, utilisez le menu de Chrome :

1. Ouvrez **diana-onff.github.io** dans Chrome.
2. Touchez les trois points **⋮** en haut à droite.
3. Touchez **Ajouter à l’écran d’accueil** ou **Installer l’application** (le nom dépend de votre version de Chrome).
4. Confirmez avec **Installer** ou **Ajouter**.

## Comment savoir si cela a fonctionné ?

- Dans les Réglages, la carte d’installation indique maintenant **« Diana est installée sur cet appareil. »**
- Diana s’ouvre sans la barre d’adresse du navigateur.

## La supprimer

Maintenez l’icône de Diana sur l’écran d’accueil et choisissez **Désinstaller** ou **Supprimer**. Attention : cela efface aussi vos réglages, comme votre indicatif et votre locator. Voir [Vos données et les limites](/fr/guide/help/data-and-limits/).
