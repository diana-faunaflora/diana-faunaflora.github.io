Sur un ordinateur, vous pouvez utiliser Diana directement dans le navigateur. Une fois installée, elle a sa propre fenêtre et une icône dans la barre des tâches ou le Dock.

## Chrome ou Edge (Windows, macOS, Linux)

1. Ouvrez **diana-onff.github.io**.
2. Cliquez sur l’**icône d’installation** à droite de la barre d’adresse (un écran avec une petite flèche), ou ouvrez le menu **⋮** et choisissez **Installer Diana**.
3. Cliquez sur **Installer**.

Vous pouvez aussi le faire depuis Diana : **Réglages** › **Installer comme application** › **Installer sur cet appareil**.

## Safari sur Mac

1. Ouvrez **diana-onff.github.io** dans Safari.
2. Dans la barre des menus, choisissez **Fichier** › **Ajouter au Dock** (macOS Sonoma ou plus récent).
3. Cliquez sur **Ajouter**.

## Firefox

Firefox ne sait pas installer d’applications web. Diana fonctionne bien dans Firefox, mais comme un onglet normal. Créez un marque-page, ou ouvrez Diana dans Chrome ou Edge si vous voulez une application installée.

:::note[La position sur un ordinateur]
Un ordinateur portable ou de bureau n’a pas de GPS. La position vient du wifi et est rarement meilleure qu’environ ±50 m. Pour savoir si vous êtes dedans ou dehors, utilisez votre téléphone sur le terrain. À la maison, le locator dans les Réglages suffit.
:::
