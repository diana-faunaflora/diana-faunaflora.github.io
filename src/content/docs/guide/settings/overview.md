Everything you set up in the wizard, and a bit more, is under **Settings**.

![The Settings screen with Your station and Your country](../../../../assets/screens/phone-settings.webp)

## Opening Settings

1. Tap **Settings** in the bottom bar (the gear, all the way to the right).
2. Scroll to the part you want to change.
3. Change it. Everything is saved at once: there is no save button. You briefly see *"Saved on this device"*.

## What is in it

| Part | What you set | Page |
|---|---|---|
| **Your station** | Callsign, portable callsign, locator | [Your station](/guide/settings/your-station/) |
| **Your country** | Which country is loaded in detail, and the spots filter | [Your country](/guide/settings/your-country/) |
| **Quick words on a spot** | Five words to add with one tap | [Quick words on a spot](/guide/settings/quick-words/) |
| **Field info** | How far around you the Areas tab looks | [Field info distance](/guide/settings/field-info-distance/) |
| **Band list when announcing** | All bands or HF only | [Band list when announcing](/guide/settings/band-list/) |
| **Language** | One of eight, or follow the browser | [Language](/guide/settings/language/) |
| **Privacy** | Privacy page, statistics, clear everything | [Privacy and statistics](/guide/settings/privacy-settings/) |
| **Install as an app** | Install on this device | [Install on Android](/guide/start/install-android/) |
| At the bottom | Version, updates, what’s new, run the wizard again | [Version and updates](/guide/settings/version-and-updates/) |

:::caution[Only on this device]
Everything you fill in here stays in the browser of this device. Use Diana on another device too? Fill it in there again. Diana has no account to link them. See [Your data and the limits](/guide/help/data-and-limits/).
:::
