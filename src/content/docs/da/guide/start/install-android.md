På Android installeres Diana som en almindelig app: et ikon på startskærmen, sit eget vindue, og den virker videre uden dækning.

## Hurtigst: inde fra Diana

1. Åbn **diana-onff.github.io** i **Chrome** (Edge og Samsung Internet virker også).
2. Tryk på **Indstillinger** nederst til højre (tandhjulet).
3. Rul ned til **Installer som app** og tryk på **Installer på denne enhed**.
4. Telefonen beder om en bekræftelse. Tryk på **Installer**.
5. Diana har nu sit eget ikon på startskærmen. Åbn den derfra fremover.

:::tip
Første gang du åbner kortet, kan Diana også vise en bjælke forneden: *"Vil du lægge Diana på denne enhed som app?"*. Tryk på **Installer** dér, så er du også færdig. Trykker du på **Ikke nu**, kommer bjælken ikke igen; knappen i Indstillinger er der altid.
:::

## Via browserens menu

Ser du ikke installationsknappen, så brug Chromes egen menu:

1. Åbn **diana-onff.github.io** i Chrome.
2. Tryk på de tre prikker **⋮** øverst til højre.
3. Tryk på **Føj til startskærm** eller **Installer app** (navnet afhænger af din Chrome-version).
4. Bekræft med **Installer** eller **Tilføj**.

## Hvordan ved jeg, at det virkede?

- I Indstillinger står der nu på installationskortet **"Diana er installeret på denne enhed."**
- Diana åbner uden browserens adresselinje.

## Fjern den igen

Hold Diana-ikonet nede på startskærmen og vælg **Afinstaller** eller **Fjern**. Bemærk: det fjerner også dine indstillinger, som kaldesignal og locator. Se [Dine data og begrænsningerne](/da/guide/help/data-and-limits/).
