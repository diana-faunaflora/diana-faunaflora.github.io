Auf einem Computer kannst du Diana direkt im Browser nutzen. Installiert bekommt sie ein eigenes Fenster und ein Symbol in der Taskleiste oder im Dock.

## Chrome oder Edge (Windows, macOS, Linux)

1. Öffne **diana-onff.github.io**.
2. Klicke rechts in der Adressleiste auf das **Installationssymbol** (ein Bildschirm mit kleinem Pfeil), oder öffne das Menü **⋮** und wähle **Diana installieren**.
3. Klicke auf **Installieren**.

Es geht auch aus Diana heraus: **Einstellungen** › **Als App installieren** › **Auf diesem Gerät installieren**.

## Safari auf dem Mac

1. Öffne **diana-onff.github.io** in Safari.
2. Wähle in der Menüleiste **Ablage** › **Zum Dock hinzufügen** (macOS Sonoma oder neuer).
3. Klicke auf **Hinzufügen**.

## Firefox

Firefox kann keine Web-Apps installieren. Diana läuft in Firefox gut, aber als normaler Tab. Lege ein Lesezeichen an, oder öffne Diana in Chrome oder Edge, wenn du eine installierte App möchtest.

:::note[Standort am Computer]
Ein Laptop oder PC hat kein GPS. Die Position kommt aus dem WLAN und ist selten besser als etwa ±50 m. Für die Frage „drin oder draußen“ nimm im Gelände dein Smartphone. Zu Hause reicht der Locator in den Einstellungen.
:::
