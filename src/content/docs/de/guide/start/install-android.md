Auf Android installiert sich Diana wie eine normale App: ein Symbol auf dem Startbildschirm, ein eigenes Fenster, und sie funktioniert auch ohne Empfang weiter.

## Am schnellsten: aus Diana heraus

1. Öffne **diana-onff.github.io** in **Chrome** (Edge und Samsung Internet gehen auch).
2. Tippe unten rechts auf **Einstellungen** (das Zahnrad).
3. Scrolle zu **Als App installieren** und tippe auf **Auf diesem Gerät installieren**.
4. Dein Smartphone fragt nach einer Bestätigung. Tippe auf **Installieren**.
5. Diana hat jetzt ein eigenes Symbol auf deinem Startbildschirm. Öffne sie ab jetzt von dort.

:::tip
Beim ersten Öffnen der Karte zeigt Diana unten eventuell auch eine Leiste: *„Diana als App auf dieses Gerät legen?“*. Tippe dort auf **Installieren**, dann bist du auch fertig. Tippst du auf **Jetzt nicht**, kommt die Leiste nicht wieder; die Schaltfläche in den Einstellungen bleibt immer da.
:::

## Über das Browsermenü

Siehst du die Installationsschaltfläche nicht, nimm das Menü von Chrome:

1. Öffne **diana-onff.github.io** in Chrome.
2. Tippe oben rechts auf die drei Punkte **⋮**.
3. Tippe auf **Zum Startbildschirm hinzufügen** oder **App installieren** (der Name hängt von deiner Chrome-Version ab).
4. Bestätige mit **Installieren** oder **Hinzufügen**.

## Woran sehe ich, dass es geklappt hat?

- In den Einstellungen steht auf der Installationskarte jetzt **„Diana ist auf diesem Gerät installiert.“**
- Diana öffnet sich ohne die Adressleiste des Browsers.

## Entfernen

Halte das Diana-Symbol auf dem Startbildschirm gedrückt und wähle **Deinstallieren** oder **Entfernen**. Achtung: Damit verschwinden auch deine Einstellungen, etwa Rufzeichen und Locator. Siehe [Deine Daten und die Grenzen](/de/guide/help/data-and-limits/).
